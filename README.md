# Bellabeat Fitness Data Analysis

## Overview
Case study analyzing Fitbit smart device data to provide 
marketing recommendations for Bellabeat, a women's wellness 
technology company.

## Tools Used
- MySQL — data cleaning & analysis
- Python (Pandas, Matplotlib, Seaborn) — EDA & visualization
- Power BI — interactive dashboard

## Key Findings
- 66% of users are sedentary or lightly active
- Users spend 81% of their day inactive
- Peak activity windows: 9AM and 6–7PM
- 80% of users sleep under 7 hours
- Saturday is most active day, Friday least active
